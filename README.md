# helly

hello! this is helly! a rust powered Discord bot enabled by poise!

this bot is meant for a private server of my friends and it's features are and will be
tailored to that group.

as of now helly can:
- be pinged
- automatically send corrected links to embed twitter, instagram, and tiktok links

## how to run helly

in its current build, helly needs two things:
- discord bot token (from discord developer portal)
- discord guild (a.k.a server) id (right click and copy the server id in developer mode)

the reason helly needs your guild is because it currently registers it's commands to the guild, not globally
this is intentionally set up for debugging purposes, but may later be changed to global!
